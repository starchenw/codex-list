# 叙野 XUYE · 餐厅官网

一个完整的单页现代中餐厅网站，包含品牌首屏、招牌菜、交互菜单、主厨故事、空间画廊、订座表单和联系信息。

## 预览

直接打开 `index.html` 即可。也可以在当前目录启动一个本地服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 说明

- 页面使用原生 HTML、CSS 和 JavaScript，无需安装依赖。
- 订座表单为前端演示交互，提交后会显示确认状态，但不会发送到真实餐厅系统。
- 品牌、地址、电话与菜单内容均为概念示例。
- 图片已本地存放于 `assets/`，来源为 Unsplash；网页字体使用 Google Fonts，并提供系统中文字体回退。
- `tools/` 内附桌面端、移动端截图和交互冒烟测试脚本，便于后续验收。
